## 23:51–01:31 — memory-sync-protocol skill 审计 + 修复

- **审计遗漏**：R5 `qmd collection update` 是错误命令，应为 `qmd update`；且 `qmd update` / `qmd embed` **都不支持 `-c` per-collection**（help 没写，跑出来才知道）

### 修复（commit dfb9a38）
- `/home/claw/.openclaw/workspace/...` → `${WORKSPACE:-~/.openclaw/workspace}/...`
- `~/.venv/memvid/bin/python3` → `$VENV_PYTHON` env + fallback 链
- `browser-memory` 硬编码 → `$QMD_COLLECTION` env
- `qmd collection update X 2>/dev/null || qmd update` → `qmd update || echo "WARN" >&2`
- 加 preflight check：`if not memvid_file.parent.exists(): raise FileNotFoundError`

### 踩坑（已补 TOOLS.md）
- `qmd update` 是全局命令，**`-c` 被静默忽略**，help 不写
- `qmd update` 实际**幂等**：0 new 0 updated 时 0 工作量
- **副作用**：browser-memory 死 collection 自动 0 files（路径不存在 → reindex 跳过）
- `qmd embed` 也无 -c，2s 跑 9 chunks

### 关键学习
- **审计时不要用 help 当真理** —— `qmd collection update` 在 `qmd collection --help` 列表里不存在，但 `qmd update --help` 也没明确说"不接受 -c"，必须真跑一次
- **patch 里 "Fallback 时不要 fallback 到不同 scope"** —— `|| qmd update`（无 -c）就是 R2 担心成真的事
