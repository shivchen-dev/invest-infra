## 迭代优化计划 (refactor-safely)

### 目标与范围
- **目标**: 解决技术债，提升代码质量和安全性
- **范围**: 
  - `src/smart_topic_manager.py`
  - `src/api/deepseek_api.py`
- **不改变**: API 接口契约、外部行为

### 技术债优先级

| 优先级 | 问题 | 影响 | 预估时间 |
|--------|------|------|---------|
| P0 | 日志脱敏 | 安全风险 | 10分钟 |
| P1 | 单元测试 | 质量保证 | 30分钟 |
| P2 | 相似度算法优化 | 功能改进 | 20分钟 |
| P3 | embedding 相似度 | 高级功能 | 40分钟 |

### 依赖与风险
- **调用方**: API 端点 (`deepseek_api.py`)
- **风险点**: 
  - 日志脱敏：需确保不影响调试
  - 测试补充：需 mock DeepSeek Bridge
  - 算法优化：需保持向后兼容

### 步骤（每步可单独提交）

#### 步骤 1: 日志脱敏 (P0)
**修改**: `src/api/deepseek_api.py`
**内容**:
- 添加日志级别控制
- 敏感信息（message, response）脱敏处理
- 生产环境只记录 metadata

**验证**:
- 语法检查通过
- 日志输出不含敏感信息

#### 步骤 2: 相似度算法优化 (P2)
**修改**: `src/smart_topic_manager.py`
**内容**:
- 修复权重计算逻辑
- 添加调试日志（可选）
- 优化中文分词（保留词组）

**验证**:
- 相似度计算测试通过
- 中文词组正确提取

#### 步骤 3: 单元测试补充 (P1)
**新增**: `tests/test_smart_topic_manager.py`
**内容**:
- 测试签名生成
- 测试相似度计算
- 测试并发锁
- 测试配置类

**验证**:
- pytest 全部通过
- 覆盖率 > 80%

#### 步骤 4: embedding 相似度 (P3, 可选)
**修改**: `src/smart_topic_manager.py`
**内容**:
- 添加可选的 embedding 支持
- 配置项控制是否启用
- 回退到关键词匹配

**验证**:
- 无 embedding 时正常工作
- 有 embedding 时更准确

### 回滚策略
- 每步独立 git commit
- 发现问题时 `git revert HEAD~n`
- 保留配置文件备份

### 开始执行
确认后执行步骤 1（日志脱敏）
