## 2. 接口协议选型

### 2.1 方案对比（DeepSeek 建议）

| 维度 | HTTP REST | gRPC | 消息队列 |
|------|-----------|------|---------|
| 可靠性 | 中（需自建重试） | 高 | 最高 |
| 调试性 | ✅ 高（curl即可） | 低 | 中 |
| 资源消耗 | 中 | 低 | 高 |
| 浏览器Agent适配 | ✅ curl模拟 | ❌ 无法模拟 | ⚠️ 过度设计 |
| 异步支持 | 需回调/轮询 | 流式 | 原生 |

### 2.2 推荐方案

**HTTP REST + 异步任务队列**（混合架构）

```python
# 同步简单问题（1-2轮）
POST /api/v1/{platform}/ask → 200 OK (直接返回)

# 异步复杂问题（多轮）
POST /api/v1/{platform}/ask/async → 202 Accepted (返回task_id)
GET /api/v1/tasks/{task_id}/status → 轮询结果
```

## 5. 轮数界定策略（DeepSeek 建议）

### 5.1 三级决策系统

```python
class ConversationOrchestrator:
    
    async def determine_strategy(self, query: str, template: str):
        # Level 1: 模板预定义
        if template in self.ONE_ROUND_TEMPLATES:
            return {'max_rounds': 1, 'strategy': 'fixed'}
        
        # Level 2: LLM意图分析（关键词检测）
        multi_round_keywords = ['流程', '步骤', '然后', '接着']
        if any(k in query for k in multi_round_keywords):
            return {'max_rounds': 5, 'strategy': 'adaptive'}
        
        # Level 3: 默认三阶段
        return {'max_rounds': 3, 'strategy': 'three_phase'}
```

### 5.2 对话结束判断

```python
class ConversationTerminator:
    END_SIGNALS = ['完整代码', '总结', '完成', '以上']
    
    def should_terminate(self, response: str, round_count: int, max_rounds: int) -> bool:
        # 达到最大轮数
        if round_count >= max_rounds:
            return True
        
        # 检测到结束信号
        if any(signal in response for signal in self.END_SIGNALS):
            return True
        
        # 连续两轮无新信息
        if self._is_redundant(response):
            return True
        
        return False
```

## 7. 架构设计

### 7.1 Bridge 工厂

```python
class BridgeFactory:
    _registry: Dict[str, Type[BaseBridge]] = {}
    _instances: Dict[str, BaseBridge] = {}
    
    @classmethod
    def register(cls, platform: str, bridge_class: Type[BaseBridge]):
        cls._registry[platform] = bridge_class
    
    @classmethod
    def get_bridge(cls, platform: str) -> Optional[BaseBridge]:
        if platform not in cls._instances:
            cls._instances[platform] = cls._registry[platform]()
        return cls._instances[platform]
```
