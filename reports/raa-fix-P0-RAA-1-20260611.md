## 2. Side findings discovered during audit (not in original RAA handoff)

These were surfaced by Sonnet 4.6 (Claude Code) during the read-only audit phase and recorded in `planning/stage1-p0-password/findings.md`:

1. **The "fix" commits regressed, not fixed.**
   - `ffdb4f9` (2026-06-02): claimed to remove hardcoded password → added `__post_init__` validation in `config.py`
   - `5b0893b` (2026-06-04): `chore: remove unused cron_alert_check.py` silently **re-introduced** `("PG_PASSWORD", "<PG_PASSWORD>")` as `setdefault` in `executor.py:38`, plus `woa_notify.py:44` and 6 `woa_tasks/task_*.py` files.
   - `5fd2b75` (2026-06-09, the "env-var fix"): added 19 lines to `cron_dispatcher.py` only. **Did not touch** `executor.py`, `woa_notify.py`, `woa_tasks/*`, `cron_*.py` scripts, or `docker-compose.yml`. 22+ leaks still present.

2. **WOA→CIA template embeds password at script-generation time.**
   - `woa_notify.py:44` `PG_PASSWORD = "***"` → `:176` `.replace("REPLACE_PG_PWD", PG_PASSWORD)` → writes `woa_tasks/task_<tid>.py` with literal `password='<PG_PASSWORD>'` inlined.
   - **A second leak path**: `cron_morning_briefing.py:169,302,304` builds a prompt string containing the literal and writes it into `cia_task_queue` via `xadd`.

3. **Untracked `.bak` file + Gitee token in remote URL.**
   - `data-pipeline/scripts/cron_pre_market.py.bak-20260611-015027` — contains literal, not in `.gitignore`.
   - `.git/config` remote URL had `https://chen-jian82:<OLD_GITEE_TOKEN>@gitee.com/...` — token baked into every clone URL.

4. **Beyond PG: MinIO/CIFANG/MCP secrets had same pattern.**
   - Legacy MinIO root creds in `docker-compose.yml`, `executor.py`, 4 cron scripts
   - `CIFANG_TOKEN`, `MCP_TOKEN` only in `data-pipeline/.env` (not `.secrets/`)
   - All co-fixed in this stage.
