## 复盘记录 - 2026-03-27

### 错误：违反记忆分层规则
- **描述**: 在 MEMORY.md 中塞了详细的 Phase 1-4 任务清单（10个技能、协作验证等具体执行项）
- **原因**: 混淆了"去哪找"和"找到什么"的分层
- **影响**: 破坏热锚点分层原则，导致"去哪找"和"找到什么"混在一起
- **正确做法**: MEMORY.md 只存"去哪找"的链接，详细内容放 memory/YYYY-MM-DD.md
- **用户纠正**: 用户指出"memory不是有他的存储规则吗？被你精简了？"
- **修正**: 删除 MEMORY.md 中的详细清单，只保留指向 memory/2026-03-27.md 的链接

### 学到的
1. MEMORY.md 是"索引"不是"仓库"
2. 加新内容前 → 先问自己"这属于去哪找还是找到什么？"
3. 用户说"已经有了" → 先搜索定位现有内容，不要直接新建

## 复盘记录 - 2026-03-28

### 严重错误：不执行技能流程
- **描述**: 听到"复盘"触发词后，手动写复盘内容，没有调用 self-improving-agent 技能
- **原因**: 混淆了"记忆分层"和"技能触发"，以为记录到 memory/ 就够了
- **影响**: 几天的复盘都未进入 `.learnings/` 技能学习目录，技能无法自动学习迭代
- **正确做法**: 听到"复盘"立即触发 self-improving-agent 技能，让技能处理存储
- **用户纠正**: "感情这几天说复盘都白总结了啊，都没记录，光说了"

### 错误：同步范围错误
- **描述**: 初始配置同步整个 workspace (497MB)，而非仅 knowledge/
- **原因**: 没有先探查 OneDrive 实际目录结构
- **影响**: 浪费带宽和时间，同步大量无关文件

### 错误：目标路径错误
- **描述**: 第一次修正后仍指向 `OpenClaw/knowledge`，而非 `ObsidianVault/Agent构建知识库`
- **原因**: 不主动查看 OneDrive 实际结构，依赖用户告知
- **影响**: 用户数据无法正确归档到 ObsidianVault

### 学到的
1. **先探查再配置**: 配置同步前应先查看目标端实际结构（`rclone lsd`）
2. **确认范围**: 同步任务必须明确"同步什么"和"同步到哪里"
3. **重要信息立即记录**: 用户告知的关键路径、结构信息应立即写入 memory
4. **验证后再报告完成**: 配置后应验证实际效果，而非仅看服务状态
5. **技能触发词必须执行技能**: 不要用手动操作替代技能流程
