> **复刻目标：** 参考集思录增强搜索插件的多维度筛选思路，构建本地化 ETF 智能筛选模块，覆盖套利信号、指数标签、多条件过滤，全量数据存数据库，接入 WOA 晨报。

## 一、插件核心能力拆解

集思录增强搜索插件的核心能力可归纳为 4 层：

| 层次 | 能力 | 对应我们系统的数据 |
|------|------|-------------------|
| **L1 数据获取** | 实时获取 ETF 折溢价、IOPV、份额、跟踪误差 | 已有 `etf.py` → `fund_etf_spot_em` |
| **L2 多维筛选** | 按指数/行业/规模/费率/成交/溢价率过滤 | 待建 `etf_screener` 模块 |
| **L3 信号输出** | 套利信号（溢价率异动 + 份额变动 + 跟踪误差） | 已有 `etf_arbitrage_signals` 表，待完善逻辑 |
| **L4 结果输出** | PostgreSQL 存储 + WOA 晨报推送 | 数据全存库，推送至晨报 |

## 三、方案设计

### 3.1 整体架构

```
┌─────────────────────────────────────────────────────┐
│ ETF 智能筛选模块 │
├─────────────────────────────────────────────────────┤
│  L1 数据采集层（现有 etf.py）                          │
│    fund_etf_spot_em → premium_rate/IOPV/volume     │
│    fund_etf_hist_em → 历史K线 │
├─────────────────────────────────────────────────────┤
│  L2 筛选引擎（新增 etf_screener.py）                  │
│    ├─ 按指数标签过滤（宽基/行业/跨境/商品）             │
│    ├─ 按溢价率过滤（溢价/折价/阈值范围）               │
│    ├─ 按流动性过滤（成交额/换手率/规模）               │
│    ├─ 按跟踪误差过滤                                  │
│    └─ 按价格位置过滤（均线偏离度）                    │
├─────────────────────────────────────────────────────┤
│  L3 信号生成层（增强 etf_arbitrage_signals） │
│    ├─ 溢价率异动信号（阈值可配置）                    │
│    ├─ 份额变动信号（配合集思录数据）                  │
│    └─ 跟踪误差异常信号                               │
├─────────────────────────────────────────────────────┤
│  L4 输出层                                          │
│    ├─ PostgreSQL 表存储（etf_screener_results）      │
│    └─ WOA 晨报推送（每日08:30前）                  │
└─────────────────────────────────────────────────────┘
```

### 3.2 目标输出表

```sql
-- ETF 筛选结果表
CREATE TABLE IF NOT EXISTS etf_screener_results (
    id SERIAL PRIMARY KEY,
    calc_date       DATE NOT NULL,
    calc_time       TIME NOT NULL DEFAULT now(),
    -- 筛选条件快照
    filter_index VARCHAR(100),        -- 跟踪指数标签
    filter_category VARCHAR(50),        -- ETF类别：stock/bond/cross_border/commodity
    filter_premium_min DECIMAL(6,4),    -- 溢价率下限
    filter_premium_max  DECIMAL(6,4),    -- 溢价率上限
    filter_amount_min   NUMERIC(18,2),   -- 成交额下限（元）
    filter_turnover_min DECIMAL(6,2),   -- 换手率下限（%）
    -- 筛选结果
    etf_id          INT REFERENCES etfs(id),
    premium_rate    DECIMAL(8,4),        -- 溢价率（‰ 千分之）
    iopv            DECIMAL(10,4),      -- IOPV
    price DECIMAL(10,4),       -- 最新价
    iopv_premium_pct DECIMAL(8,4),      -- (price/iopv - 1) * 100
    amount          NUMERIC(18,2),      -- 成交额（元）
    turnover_rate DECIMAL(6,2),        -- 换手率（%）
    volume          BIGINT,             -- 成交量
    change_pct      DECIMAL(8,2), -- 涨跌幅（%）
    amplitude DECIMAL(8,2),        -- 振幅（%）
    ma20_pct        DECIMAL(8,2),       -- 相对20日均线位置（%）
    ma60_pct        DECIMAL(8,2),       -- 相对60日均线位置（%）
    signal_type VARCHAR(50),         -- 信号类型：premium_alert/liquidity_alert
    signal_level VARCHAR(20),        -- 信号级别：high/medium/low
    created_at       TIMESTAMP DEFAULT NOW(),
    UNIQUE (calc_date, etf_id, filter_index, filter_category)
);

-- ETF 指数标签映射表（插件热门指数标签的数据层支持）
CREATE TABLE IF NOT EXISTS etf_index_tags (
    id          SERIAL PRIMARY KEY,
    index_code VARCHAR(50) NOT NULL, -- 指数代码，如000300（沪深300）
    index_name  VARCHAR(100), -- 指数名称
    etf_id      INT REFERENCES etfs(id),
    tag_type    VARCHAR(30),                -- wide_base（宽基）/ sector（行业）/ cross_border
    created_at  TIMESTAMP DEFAULT NOW(),
    UNIQUE (index_code, etf_id)
);
```

### 3.3 核心脚本

| 脚本 | 职责 | 触发方式 |
|------|------|---------|
| `sync_etf_spot_daily.py` | 每日盘后采集全量 ETF 实时行情 | cron（交易日后 16:00） |
| `etf_screener.py` | 多维度筛选引擎，生成 `etf_screener_results` | cron（交易日后 16:05） |
| `etf_arbitrage_signal.py` | 套利信号生成（溢价率异动 + 份额变动 + 跟踪误差） | cron（交易日后 16:10） |

## 四、筛选条件设计（复刻插件多维筛选）

### 4.1 预设筛选场景（对应插件的快捷标签）

| 场景 | 条件 | 用途 |
|------|------|------|
| **宽基 ETF** | `category = 'stock'` + `index_name 匹配沪深300/中证500/创业板等` | 被动跟踪大盘 |
| **行业 ETF** | `category = 'stock'` + `index_name 匹配具体行业` | 行业轮动 |
| **跨境 ETF** | `category = 'cross_border'` | 分散风险 |
| **黄金/商品** | `category = 'commodity'` | 避险/通胀 |
| **溢价率异常** | 按类型分级阈值（宽基±0.3%/行业±0.5%/QDII±1.5%） | 套利机会监控 |
| **高流动性** | `amount > 1亿元` + `turnover_rate > 5%` | 短线操作必备 |
| **低费率 ETF** | `fee< 0.2%`（需补充数据源） | 长期持有成本 |
| **价格位置适中** | `ma20_pct ∈ [-10%, +10%]` | 均值回归候选 |

### 4.2 可配置参数

```python
# etf_screener.py 配置
SCREENER_CONFIGS = {
    "wide_base": {
        "categories": ["stock"],
        "index_patterns": ["沪深300", "中证500", "中证1000", "创业板", "科创板"],
        "premium_range": (-0.3, 0.3),   # 宽基 ETF 阈值 ±0.3%（套利效率高，溢价极小）
        "amount_min": 1e8,
    },
    "sector_rotation": {
        "categories": ["stock"],
        "index_patterns": ["光伏", "军工", "半导体", "AI", "医药"],
        "premium_range": (-0.5, 0.5),   # 行业 ETF 阈值 ±0.5%
        "amount_min": 5000e4,
    },
    "qdiihigh": {
        "categories": ["cross_border"],
        "premium_range": (-1.5, 1.5),  # QDII 阈值 ±1.5%（外汇管制+跨境时滞天然偏大）
        "amount_min": 5000e4,
    },
    "arbitrage_monitor": {
        "categories": ["stock", "cross_border"],
        "alert_threshold": 0.5,         # 兜底通用阈值（‰ 千分之）
        "amount_min": 5000e4,
    },
}
```

## 五、与现有系统的集成关系

### 5.1 复用现有数据链路

```
已有链路：
fetch_etf_spot() → etfs 表（基本信息）→ 已有

新增链路：
fetch_etf_spot() 
    → sync_etf_spot_daily.py（增量写入 etf_spot_snapshots）
    → etf_screener.py（读快照 + 计算均线偏离度）
    → etf_screener_results（输出）
    → etf_arbitrage_signal.py（读溢价率 → 信号）
```

### 5.2 与 WOA 晨报集成

`etf_screener_results` + `etf_arbitrage_signals` 作为晨报固定数据源，08:30 前生成：


```
📊 ETF 信号速览
├─ 溢价率异动 TOP3（>阈值，分类列出）
├─ 宽基 ETF 折溢价中位数（大盘情绪温度计）
└─ 今日重点方向信号（行业 ETF 价格位置提示）
```

## 八、风险与限制

| 风险 | 说明 | 缓解措施 |
|------|------|---------|
| akshare 接口稳定性 | `fund_etf_spot_em` 可能被限流 | `retry` 装饰器 + 失败告警 |
| 溢价率数据缺失 | 部分 ETF 无 IOPV 数据 | 区分有/无 IOPV 分别处理 |
| 均线计算性能 | 全市场 ETF 计算均线耗时长 | 分批计算 + 增量更新 |
