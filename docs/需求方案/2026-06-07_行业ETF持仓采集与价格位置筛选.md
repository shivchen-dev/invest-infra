# 行业ETF持仓采集与价格位置筛选

## 背景

用户需求：从行业ETF基金的前十大持仓股票中，筛选出"价格位置适中"的标的。

**核心问题：** 系统当前既无ETF持仓明细表，也无相关MCP工具。

---

## 现状分析

### 数据缺口

| 项目 | 状态 |
|------|------|
| 本地 `etfs` 表 | 只有基本信息（代码/名称/跟踪指数），无持仓字段 |
| `wudao_aStock` MCP工具 | **无** ETF成分股/持仓明细接口 |
| 基金季报 | 每季度结束后15个工作日内披露，存在天然延迟 |

### 现有替代方案对比

| 方案 | 数据源 | 覆盖度 | 实时性 | 实现成本 |
|------|--------|--------|--------|---------|
| **AKShare** `fund_portfolio_hold_em` | 天天基金网 | 全部公募基金 | 季报披露后次日 | 低（pip install即可） |
| 爬取东方财富/天天基金 | 网页爬虫 | 可定制 | 季报披露后次日 | 中（需维护反爬） |
| 专业数据API（Wind/Choice） | 商业数据商 | 完整 | 次实时 | 高（需付费） |

## 方案设计

### 方案一：AKShare 接口（季报持仓）

**核心接口：**
```python
import akshare as ak

# 获取基金持仓（前二十大重仓股）
df = ak.fund_portfolio_hold_em(code="512480", year=2025)
# 返回字段：季度、股票代码、股票名称、持仓比例、持股数、持仓市值
```

**数据源地址：** `https://fundf10.eastmoney.com/ccmx_{code}.html`

**数据更新频率：** 每季度（基金季报披露，滞后约15个工作日）

---

### 目标输出表设计（方案一）

```sql
CREATE TABLE etf_holdings (
    id          SERIAL PRIMARY KEY,
    fund_code   VARCHAR(10) NOT NULL,          -- ETF代码，如512480
    fund_name   VARCHAR(100),
    trade_date  DATE NOT NULL,                 -- 持仓报告期（季度末）
    rank        SMALLINT NOT NULL,             -- 1-20，重仓排名
    stock_code  VARCHAR(10), -- 持股代码，如600519
    stock_name  VARCHAR(100),
    holding_pct DECIMAL(6,4),                  -- 持仓比例（0.0800 = 8%）
    shares      BIGINT,                        -- 持股数量
    market_val  DECIMAL(18,2), -- 持仓市值（元）
    created_at  TIMESTAMP DEFAULT NOW(),
    UNIQUE(fund_code, trade_date, rank)
);
```

### 方案二（推荐）：实时板块成分股筛选

> **核心思路：用盘中实时数据替代季报持仓，时效性更强。**

**流程：**
```
强势行业识别（sector_analysis）
    ↓
行业内成分股（stock_screener）
    ↓
价格位置适中筛选（ma20/ma60 + 涨幅 + 量比）
    ↓
输出候选标的列表
```

**工具链：**

| 步骤 | 工具 | 数据 |
|------|------|------|
| 1. 识别强势行业 | `sector_analysis` | 60日涨幅 + 5日强度 |
| 2. 获取行业成分股 | `stock_screener`（conceptKeywords） | 按行业筛选 |
| 3. 补充K线数据 | `kline` | ma5/ma10/ma20/ma60 |
| 4. 价格位置判断 | `valuation_snapshot` | 现价/PE/PB/市值 |
| 5. 最终筛选 | 本地计算 | 均线偏离度 + 涨幅 + 量比 |

**与方案一的关系：**

| 维度 | 方案一（季报持仓） | 方案二（实时成分股） |
|------|------------------|---------------------|
| 数据时效 | 滞后约4个月 | 盘中实时 |
| 覆盖范围 | 机构认可的持仓方向 | 全市场所有股票 |
| 参考价值 | 验证机构配置方向 | 核心筛选依据 |
| **综合** | **辅助参考（20-30%）** | **核心依据（70-80%）** |

**两者结合：**
- 方案二筛选出候选股后，用方案一的季报持仓验证「机构是否也配置了这些股票」
- 如果某只股票在方案二筛选中表现好，且季报中机构持仓增加 → 信号加强
- 形成「**实时筛选 + 季报验证**」双重确认体系

## 采集流程

```
每日/每周 cron
    │
    ▼
1. 获取ETF列表
   fund_name_em() → 筛选 ETF 类型
   │
    ▼
2. 每周触发采集
   判断在 1/4/7/10 月中下旬（季报披露窗口）
   │
    ▼
3. 遍历每只ETF调用 fund_portfolio_hold_em()
   │
    ▼
4. 写入 etf_holdings 表
   │
    ▼
5. 价格位置计算（可选，作为后续步骤）
   结合日K线数据，计算每只持仓股的均线偏离度
```

## 筛选逻辑：价格位置"适中"

**定义：** 价格在均线附近（未极端偏离），近期涨幅适中

**量化标准：**

| 维度 | 条件 | 说明 |
|------|------|------|
| 20日均线位置 | `ma20 * 0.95 ≤ price ≤ ma20 * 1.05` | 在20日均线±5%以内 |
| 60日均线位置 | `ma60 * 0.90 ≤ price ≤ ma60 * 1.10` | 在60日均线±10%以内 |
| 20日涨幅 | `-15% ≤ close_pct_chg_20d ≤ 30%` | 不过高或过低 |
| 量比 | `≥ 1.0` | 成交量正常 |
| ST/退市 | 剔除 | 过滤风险股 |

**分类标签：**
- 🟢 稳健型：同时满足 ma20±5% + ma60±10%
- 🔵 进取型：price > ma20 且趋势向上
- 🟡 超跌型：price < ma20 10%以上，有均值回归可能
