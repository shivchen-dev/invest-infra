# 盘前报格式规范 v1.0

**版本：** 1.0
**日期：** 2026-06-08
**依据：** WOA Morning Briefing 对比测试结果
**状态：** 生效

---

## 一、格式结构

```
📊 盘前报 {date}
==================

【WOA 工作摘要】
（表格：任务 | 状态 | 置信度）
综合置信度：X | 风险：X | 建议关注：X

【今日市场概况】
（数据 + 来源标注）

【因子信号】
（表格：因子 | 信号 | 置信度 | 数据状态）

【ETF 信号】
（表格：ETF | 信号 | 综合评分 | 置信度）

【风险提示】
（风险等级 + 触发信号 + 来源标注）

【情景假设】
（中性/悲观/乐观三行）

【今日关注】
（优先级列表）

⚠️ 只输出分析结论，不提供投资建议 | 数据从 PG investment_memos 读取，不主观臆断
```

---

## 二、字段规范

### 置信度标注（中文）
| 英文 | 中文 |
|------|------|
| HIGH | 高 |
| MEDIUM | 中 |
| LOW | 低 |

### 数据来源标注格式
```
【来源：表名.字段名，数据日期】
例：【来源：index_quotes，数据 2026-06-05】
```

### WOA 工作摘要表格
| 列 | 内容 |
|---|------|
| 任务 | morning_collect / factor_calculation / etf_alpha_signal / risk_monitoring / daily_report |
| 状态 | ✅ 完成 / ⚠️ API限流降级 / ❌ 失败 |
| 置信度 | 高 / 中 / 低 |

### 摘要底部三要素
- **综合置信度：** 高 / 中 / 低
- **风险：** 具体风险描述（无风险写"无明显风险"）
- **建议关注：** 1-2条核心关注方向

---

## 三、六板块内容规范

### 3.1 今日市场概况
- 沪深300点位 + 涨跌幅【必须】
- 情绪判断【必须】
- 成分股异动（选代表性，3-5只）【可选】
- 来源标注

### 3.2 因子信号
| 因子 | 信号 | 置信度 | 数据状态 |
|------|------|--------|----------|
- 5类：动量、价值、质量、资金流、技术面
- 信号：看多 / 中性 / 看空 / 数据缺失 / 无区分度
- 数据状态：具体数值或缺失原因

### 3.3 ETF 信号
| ETF名称 | 信号 | 综合评分 | 置信度 |
|------|------|---------|--------
- Top 5 ETF，按综合评分排序
- 信号类型：关注 / 防御配置 / 回避

### 3.4 风险提示
- 风险等级：低 / 中 / 高
- 波动率数值 + 来源
- 三项检查结果（流动性/集中度/情绪）
- VIX数值
- 地缘风险星级（★★★★★）

### 3.5 情景假设
| 情景 | 概率 | 条件 | 预期 |
|------|------|------|------|
- 三行：中性 / 悲观 / 乐观

### 3.6 今日关注
- 优先级列表，1-4条
- 每条包含方向和依据

---

## 四、禁止词
- 买 / 卖 / 持有 / 做多 / 做空 / 推荐 / 建议买入 / 建议卖出
- 只能用：监控 / 关注 / 复核 / 进一步分析

---

## 五、数据来源优先级
1. PG investment_memos（WOA 写入，company_id=5233）
2. 数据缺失时如实标注「无数据/数据缺失」，禁止推断

---

## 六、触发流程

```
WOA 执行
  ├─ 写 PG investment_memos（5条 memo）
  ├─ 写 cia_task_queue（带 prompt + woa_summary）
  └─ 发 QQ 消息给 CIA：
     「✅ Morning Briefing 完成 msg_id={cia_msg_id} 请生成盘前洞察」

CIA 收到消息
  ├─ 解析 msg_id
  ├─ 从 cia_task_queue 读 prompt
  ├─ 从 PG investment_memos 读今日数据
  ├─ 按本格式生成盘前报
  ├─ 发 QQ
  └─ XACK cia_task_queue
```
